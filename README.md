Controle de Níveis de Água

Sobre o projeto

Sistema simples de monitoramento de um reservatório de água, desenvolvido em Python.

O programa apresenta cinco níveis de água, cada um associado a uma mensagem e uma cor específica utilizando a biblioteca Colorama.

Tecnologias utilizadas

- Python
- Biblioteca Colorama

Níveis do reservatório

1. Nível 1: Muito baixo (vermelho).
2. Nível 2: Baixo (amarelo).
3. Nível 3: Médio (verde).
4. Nível 4: Alto (ciano).
5. Nível 5: Muito alto (azul).

Como executar

1. Instale a biblioteca:
   "pip install colorama"
2. Execute o arquivo "main.py".
